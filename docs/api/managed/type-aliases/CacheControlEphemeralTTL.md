# Type Alias: CacheControlEphemeralTTL

> **CacheControlEphemeralTTL** = `string`

The time-to-live for the cache control breakpoint.

This may be one the following values:

- `5m`: 5 minutes
- `1h`: 1 hour

Defaults to `5m`.
